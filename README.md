# Mini Discord

แอปแชท + วิดีโอคอลขนาดเล็ก คล้าย Discord รองรับ:

- 💬 **ห้องแชทกลุ่ม** สร้างห้องใหม่ได้ไม่จำกัด ส่งข้อความได้โดยไม่ต้องโทร
- 📩 **ข้อความส่วนตัว (DM)** คลิกชื่อผู้ใช้ในลิสต์เพื่อคุยแบบส่วนตัว
- 📞 **โทรเดี่ยว 1-1** กดปุ่มโทรข้างชื่อผู้ใช้ มีสายเรียกเข้าให้กด รับ/ปฏิเสธ
- 👥 **โทรกลุ่ม (วิดีโอคอลหลายคน)** กด "เข้าร่วมช่องเสียง" ในแต่ละห้อง คุยพร้อมกันได้หลายคนแบบ mesh
- 📱 **Responsive** ใช้งานได้ทั้งคอมพิวเตอร์ มือถือ และไอแพด (sidebar พับเป็นเมนูบนจอเล็ก)

## วิธีติดตั้งและรัน

```bash
npm install
node server.js
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

เปิดหลายแท็บ/หลายเครื่องที่อยู่ในเครือข่ายเดียวกัน (หรือ deploy ขึ้นเซิร์ฟเวอร์จริง) เพื่อทดสอบแชทและวิดีโอคอลระหว่างผู้ใช้หลายคน

> ⚠️ วิดีโอคอลต้องใช้งานผ่าน **HTTPS** หรือ **localhost** เท่านั้น (ข้อจำกัดของเบราว์เซอร์ในการขอสิทธิ์กล้อง/ไมค์) ถ้า deploy ขึ้นเซิร์ฟเวอร์จริงต้องมี SSL certificate

## โครงสร้างไฟล์

```
server.js              ตัวเซิร์ฟเวอร์ Express + Socket.io (ห้อง, DM, สัญญาณโทร)
public/
  index.html            หน้าเว็บหลัก
  css/style.css          สไตล์ + responsive design
  js/app.js              โค้ดฝั่ง client (แชท, DM, PeerJS สำหรับวิดีโอคอล)
```

## เทคโนโลยีที่ใช้

- **Express** เสิร์ฟไฟล์หน้าเว็บ
- **Socket.io** ส่งข้อความแชท/DM แบบเรียลไทม์ และเป็นตัวกลางส่งสัญญาณ (signaling) สำหรับวิดีโอคอล
- **PeerJS (WebRTC)** เชื่อมต่อวิดีโอ/เสียงโดยตรงระหว่างเบราว์เซอร์ (peer-to-peer)

## หมายเหตุ

ข้อมูลทั้งหมด (ข้อความ, ห้อง, ผู้ใช้ออนไลน์) เก็บไว้ใน **memory** ของเซิร์ฟเวอร์เท่านั้น หากรีสตาร์ทเซิร์ฟเวอร์ ข้อมูลจะหายไปทั้งหมด เหมาะสำหรับใช้ทดสอบ/เดโม ถ้าต้องการใช้งานจริงจังควรต่อฐานข้อมูล (เช่น MongoDB/PostgreSQL) เพิ่มเติม
